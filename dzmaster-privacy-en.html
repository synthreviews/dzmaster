Privacy Policy

What actually happens to your file

Last updated: September 21, 2026

This page isn't meant to be generic legal boilerplate — it's meant to give you a specific, honest answer to "what does DZMASTER do with my music file, and what data does it collect about me?" Short version: your file never leaves your device, and we collect practically no personal data about you — apart from two narrowly scoped exceptions described below (an anonymous visit counter and a hashed IP address used for the free-tier limit). The longer version is below.

1. Who runs this site

DZMASTER is a tool from the SYNTHLUCIDA family, run as an independent, free web app with no company registration behind it, hosted on GitHub Pages.

2. What happens to your audio file

When you select or drop a WAV file into DZMASTER, it is never sent to any server — not ours, not anyone else's. Every step — analysis (loudness, peaks, dynamics) and processing itself (EQ, compressor, limiter, export) — runs entirely inside your browser via JavaScript (a Web Worker), on your own device.

The file only lives temporarily in your browser's memory for as long as the page is open. Once you close or reload the page, the processed data and the temporary references to it (so-called blob URLs) are gone. We never store, back up, or have access to it — technically we can't even see it, because it never reaches us in the first place.

The one exception where the page contacts a server at all is a short check — "has this IP address already used its one free mastering this calendar month?" — described in section 5 below. That check never includes or sees your file or any part of its content, only an anonymous yes/no answer.

In other words: DZMASTER has no backend that receives files. There's no database, no storage, nothing to breach or misuse, because your music never leaves your computer or phone.

3. Personal data we do not collect

  • No account or sign-up of any kind
  • No name, email, or other contact details
  • No tracking or advertising cookies
  • No cross-site tracking and no profile built about you
  • No sharing of data with third parties — because we never receive any data from you worth sharing

Two narrow exceptions — an anonymous visit counter and a hashed IP address used for the free-tier limit — are described in sections 5 and 6.

4. What is stored locally in your browser

DZMASTER keeps two things in your browser's localStorage, neither ever sent anywhere: your language choice (Czech/English), so the page opens in the same language next time, and whether you've unlocked the tool with a purchased code, so it doesn't ask you for the code again. You can clear either any time via your browser's site-data settings.

5. The free-tier limit and hashed IP address

The free Smart Auto preset is capped at 1 mastering per calendar month per IP address. Before that limit is used up, clicking "Process" first sends a simple check to a small server-side function (Firebase Cloud Functions) asking whether your IP address has already used its limit this calendar month.

  • Your IP address is converted into a one-way hash (HMAC-SHA256 with a secret key) the instant the request arrives — only that hash, together with the month, is stored (in Firestore), never the IP address itself, and the hash cannot be reversed back into an IP address.
  • The stored record contains nothing else — no file, no track name, no browser or device identifier.
  • The record is deleted automatically roughly 60 days after it's created (a technical "expiry" in the database) — it isn't kept beyond that.
  • Once you unlock DZMASTER with a purchased code, this check is skipped entirely — unlocked mastering has no limit, and no IP address is involved at all.
  • If this server-side function is ever unreachable for any reason (an outage, a slow connection), the tool simply doesn't enforce the limit and processing proceeds — a failure on our end never blocks legitimate use.

6. Visit counter (GoatCounter)

For a basic sense of how many people open this page, we use GoatCounter, a privacy-focused analytics tool that doesn't use cookies, doesn't store your IP address against an individual visit, and doesn't build a profile of you or track you across other sites. We only see aggregate numbers (page view counts, broad device/browser type), never who specifically visited. Details are in GoatCounter's own privacy policy.

7. Hosting and technical data

This site runs on GitHub Pages (GitHub, Inc., part of Microsoft). Like on any website, GitHub as the hosting provider may record standard server operation logs on its end — typically an IP address, browser type, and request timestamp. DZMASTER has no access to this data and does not perform any comparable logging of its own. The free-tier limit described in section 5 runs on Firebase (Google) — the same kind of standard infrastructure-provider operational logs may exist there too, again nothing we collect or review ourselves. Details are available in GitHub's own privacy statement and Firebase/Google's privacy policy.

8. Cookies

DZMASTER itself sets no cookies, and GoatCounter (section 6) is deliberately cookie-free by design. The only local trace is the localStorage entries mentioned above (language, unlock status) — technically not cookies, and never sent to a server.

9. Your rights

Because we don't process your name, email, or any other directly identifying detail through your use of DZMASTER, there is in practice nothing to correct or export. The hashed IP record used for the free-tier limit (section 5) also deletes itself automatically after roughly 60 days. If you still have any question about privacy here, or something doesn't add up, reach out via the contact below.

10. Changes to this policy

If anything about how the tool works changes in a way that affects data processing, this page will be updated and the date at the top will change. Feel free to check back if you care about the details.
